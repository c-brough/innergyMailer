Linux

Linux has no Outlook desktop app, so Outlook on the web is the reliable route — the draft is created in your Microsoft 365 mailbox and opened in a new tab. Default mail client needs a mail app actually installed (Raspberry Pi OS ships none); without one, InnerCider refuses rather than opening a compose window with the PDF missing.

All platforms

Pops a compose window inside Innergy and sends through your Microsoft 365 account (Graph) when you click Send — the PO PDF is attached. Works on any OS; no desktop mail app needed.

One-time Azure setup (uses the same Client ID as the Graph sign-in above):
  1. In your Azure app → Authentication → Add a platform → Mobile and desktop applications → add this redirect URI:
    loading…
  2. Under API permissions → Microsoft Graph → Delegated → add Mail.Send.
  3. Paste the Client ID in the Microsoft Graph sign-in box below. The first time you click Send, a Microsoft sign-in window appears; after that it's remembered.
Azure App Registration — one-time setup
  1. Go to portal.azure.com → App registrations → New registration.
    Name: anything (e.g. InnerCider)
    Supported account types: Accounts in any organizational directory and personal Microsoft accounts
    Redirect URI: leave blank → click Register
  2. Copy the Application (client) ID from the overview page.
  3. Under API permissions → Add a permission → Microsoft Graph → Delegated → add Mail.ReadWrite.
  4. Paste the Client ID below and click Sign in. A browser tab opens — sign in with your Microsoft account. The token is cached so you only do this once.
Microsoft Graph sign-in

Which Innergy export to attach when you click Draft Email w/ PDF:

Email body

The line-item summary always lists each material with its quantity and project/work order. Pricing is hidden by default.

BOM app backlinks optional

If your shop pushes work-order shipment items from a BOM app, enter its address and each pushed item gets a BOM ↗ link back to the BOM it came from. Leave blank if you don’t use one — the feature stays off.

Time Tracking Tools opt-in

For timekeepers who edit and approve time. When on, selecting two adjacent time segments for the same employee adds in-grid buttons to fill or split the gap between them. Leave off if you don’t manage time entry.
